   now have evidence-backed dispositions, large mixed OpenAI/harness tests are
   split into direct mechanisms and public composition, and the source graph
   is cycle-free without changing product behavior.
2. *What final direction does this move toward?*  One semantic owner per
   established concern, with facades as application composition roots,
   explicit state lifetimes, and narrow downstream contracts.
3. *What is uncertain versus stable?*  Durable formats, public commands,
   protocol behavior, and state-machine ordering are stable.  Future SQLite,
   richer canvas artifacts, permission policy, and shell lifecycle are
   explicitly Planned/unconfirmed; no speculative abstraction hides them.
4. *Who owns each behavior and why?*  The matrices above place each state and
   side effect in its semantic owner: aggregate, codec, storage, harness
   substate, board, context lifetime, turn stream, Work, presentation owner,
   provider, MCP transport/client, or base file/bash owner.
5. *Does coupling increase or decrease?*  It decreases: private consumer edges
   became semantic projections or direct owner tests, owner graphs are
   directional, and the higher-level budget owner no longer loads from the
   context owner.

   no owner calls its facade, no external chat/session/default consumer calls a
   moved private operation, and context-lifetime no longer loads budget.
