* Architecture review

Chat owns both presentation optimizations.  The loop retains provider-neutral
lifecycle facts and no longer names process-reporting segments or tools.  The
process-reporting capability owns the expensive opt-in counterfactual and its
durable record.  No new shared shell/window exception or cross-component chat
knowledge was introduced.

* Design self-check

1. Each commit is independently useful: incremental timer rendering, removal
   of unconditional accounting, then bounded live history.
2. The direction is bounded shell presentation and capability-owned optional
   diagnostics around a provider-neutral harness.
3. The configurable round count is local and reversible; stable ownership is
   modeled directly without a new extension framework.
4. Chat owns rendering; process reporting owns marker accounting; the loop owns
   request lifecycle.
5. Coupling is reduced: marker names disappeared from core, and no other shell
   needs to know about chat presentation.
6. Stable core policy has no dependency on the process-reporting capability.
7. Presentation mutation stays in chat and diagnostic persistence stays in the
   capability boundary.
8. No durable state was added to chat.  Explicit diagnostic shapes use the
   existing session process-report store; live projection state remains local.
9. Ordinary requests eliminate four full serialization/hash passes.  Progress
   ticks edit only the active tail, and full live projections render at most 12
   recent rounds by default.
10. No substitutable interface or speculative adapter was added.
11. Existing persisted request-shape records remain readable; ordinary new
    requests intentionally stop creating them.
12. Marker-specific loop and harness projection code was removed.
13. Explicit measurement rejects incomplete records; unexpected persistence
    errors surface through the existing process-reporting path.
14. Focused tests prove each invariant independently, and graphical tests prove
    native redisplay, geometry, timer, and tool-list behavior.
