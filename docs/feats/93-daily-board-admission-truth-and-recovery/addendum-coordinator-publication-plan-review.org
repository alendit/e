* Completeness decisions

- Deadline ownership is closed: absolute deadline/timer/cancellation remain in
  =e-work=; =e-subagent-runner= alone converts settlement to one Board report.
- Required information is closed: the manifest produces the immutable run
  deadline, Board terminal projection produces typed task results/gaps, and the
  reconciliation result supplies the complete section map.
- Transaction/recovery is closed: validate before write; materialized remains
  an internal recoverable phase; commit uses the exact admitted paths; durable
  published/finalized evidence fences retry.
- The model is no longer a workflow coordinator.  Its only side effect is the
  narrow typed reconciliation result handoff.
- Generic topic commit has an exact consumer-shaped exclusion and cannot become
  a second Daily writer.
- DP1 and DP2 are useful stopping points with one dependency direction; no
  partial publication package exists.
- Stable formats and Board identity remain compatible.  The obsolete ordinary
  =:apply=/=:finalize= caller path and mechanism tests are explicitly removed or
  made private.
- Repository-controlled scenarios cover positive, invalid, timeout, late,
  restart, hook, and configured cold-start partitions.  No external capability
  is required for acceptance.
