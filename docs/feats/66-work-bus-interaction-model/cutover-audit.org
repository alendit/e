#+title: Work bus cutover completion audit

* Scope

This audit records the repository state after the Slice 5 board-only source
cut.  It covers admission/quiescence, public presentation, bundled producers,
retired paths, bounded work, and restart disposition.

The audit is repository-side.  The running Emacs and user session stores were
not reloaded, prepared, or mutated.

* Result

Complete in source.  One O(1) admission epoch plus bounded owner-local indexes
can authorize runtime quiescence.  Public shells and bundled producers enter
through explicit board application services/bindings, and structural tests
reject the superseded direct live-session paths.

A full Emacs restart is required to activate the cardinal runtime cut.  No
same-process handoff or =e-dev-reload= was attempted.

* Admission and quiescence

=e-board-runtime-quiescence-start= closes the admission epoch in constant time
and returns a controlled request.  It composes named, constant-time unsettled
projections from:

- board routing, pickups/receipts, effects, and registry work;
- runtime controls, invocations, deferred hooks, pickup/activity/producer queues;
- aggregate harness active turns and queued/steering input;
- =e-work= nonterminal handles;
- session persistence writer outboxes.

Each owner advances a monotonic generation and notifies the request on its own
state transition.  The request neither polls nor scans.  Cancellation keeps
admission closed, and only the opaque token for the current fence can reopen
that epoch.

Held-owner regressions prove every blocker class prevents a green result and
settles from notification.  Accepted internal continuations may finish after
the fence without admitting a new root.

* Public source cut

The core =e-chat-service= owns one board/client/requester/observer binding per
live chat session.  It is the only public application seam for create, submit,
queue, steer, abort, subscription, transcript projection, activity projection,
and session metadata reads.

The chat, starter, debug, Org Canvas, modernchat, and chat-session capability
paths use that service.  Shell observers receive immutable board-message
translations and schedule UI mutation through =e-ui-work=.  They do not own a
harness subscription, active-turn table, or transcript fallback.

The structural cutover test scans every public shell and the chat capability
ingress for retired live harness symbols.

* Bundled producers

Task queue, cron, background triggers, annotation answer/sweep, and subagent
registry changes publish facts through =e-board-runtime-producer-binding=
records.  A binding captures live board identity, producer epoch,
tags/attributes, and stable source-key sequencing.

Missing/stale bindings fail visibly and cannot start work.  Zero matches remain
unrouted and create no participant.  Arbitrary cron callbacks, background/task
lazy session creation, annotation session-context export, and task metadata
repair were removed.  Subagent child sessions enter through the board-backed
chat service and registry state changes publish to the parent board.

* Correctness fences

- Frozen requester authority and exact-target grants are rechecked before
  delivery and acceptance reconciliation.
- Principal revocation advances client generations and closes owned observers
  through bounded scheduled work.
- Deferred routing retains historical selector bytes but resolves current
  subscription lifecycle before pickup/effect creation.
- Invocation effects freeze and revalidate opaque endpoint token plus composite
  instance/harness/session generation.
- Retryable pickup failures stay scheduler-owned; exhaustion is visible, other
  lanes continue, and every terminal turn edge releases eligible FIFO work.

* Bounded execution

Board events/messages use owner-local tail cells and an ordinal message index.
Observer history/live pages address bounded windows without prefix scans or
whole-log reversal.  Registry paging uses an ordered AVL successor index.
Classification, effects, pickups, activity, hooks, producers, observers, and UI
handoff each have explicit record/work/page budgets and yield between pages.

The nonblocking-boundary and direct-render guards pass without new allowlist
entries.

* Retired surface

The repository contains no public model-facing =:handler= or executable
=:start= registration branch, no public shell or bundled-producer direct
create/prompt/queue/steer/abort/subscribe path, no annotation session-context
export, no arbitrary cron coordination callback, no task metadata migration,
and no one-shot cutover-preparation command.

Private harness/session operations remain inside core/runtime adapters where
their meaning lives; they are not presentation or producer entrypoints.
