#+title: Retired cutover preparation design
#+startup: overview

* Status

Retired on 2026-08-03.

The proposed offline session preparation and compatibility lifecycle were not
part of the final board framework.  No preparation command, schema conversion,
discovery service, or migration path is supported.

New chat sessions persist their =board-id= and trusted =principal= before the
main participant is attached.  A restart reconstructs that board from the
session journal.  Sessions without board identity are intentionally absent
from chat navigation and resume.
