#+title: Bound Resource Search Output
#+startup: overview

* Status

Done

* Change

The default resource-search result limit is 20.
The asynchronous =file://= and =tmp://= search paths parse =rg --json= incrementally and stop the process after observing =limit + 1= matching candidates.
They retain at most =limit= candidates, use the extra candidate to set =:truncated=, and avoid copying and splitting the complete process output.
Advanced searches that require whole-resource evaluation retain their existing path.
