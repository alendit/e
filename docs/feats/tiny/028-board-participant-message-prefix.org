#+title: Board Participant Message Prefix

* Status

Done.

* Change

Persist the admitted participant display name with each canonical Board output
and project it into detached message events.  Chat presentation prefixes only
non-selected assistant messages as =[participant name] message=.  The stored
message content itself remains unchanged.

Participant admission derives the name from explicit participant metadata,
the subagent label, or the session name.  Reopening a live binding reads the
name once from SQLite's current participant row; there is no participant map,
message-time lookup, or second durable state owner in Emacs.

This is tiny because it adds one bounded attribution field and one presentation
rule.  The broader Board chat/activity design remains separate work.
