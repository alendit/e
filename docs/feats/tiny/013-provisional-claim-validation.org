#+title: Provisional Claim Validation

* Change

Keep the first Bayesian answer as the only main-chat answer while its private
validation follow-up runs.

The hook publishes the follow-up through the attached board with the
=bayesian-reasoning-validation= tag.  The board delivers that exact-addressed
input back to the participant, and the runtime carries the tag through all
activity and output for the validation turn.  Main chat observers select only
=main=, so they never project the validation input, progress, or output.

The board remains the durable interaction log.  No chat-specific hiding or
private-message-to-board-message reconciliation is required.  The validation
reply remains hidden in the private transcript so it does not enter ordinary
model context.

* Validation

- Bayesian hook tests cover accepted and rejected private validation.
- The board/chat integration test covers routing-tag inheritance and proves a
  =main= observer receives only the first assistant output.
