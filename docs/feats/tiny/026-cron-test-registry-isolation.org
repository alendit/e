#+title: Cron Test Registry Isolation

* Status

Done.

* Change

Keep the cron-action test fixture's private board table coherent with a private
board index and private unsettled aggregate state.  Previously the fixture
replaced only the table, so creating its first board reset process-wide counters
that still belonged to an outer board.  Delayed outer routing decrements then
made later, otherwise unrelated tests fail with negative board counts.

Add a regression that leaves one outer route pending, enters and exits the cron
fixture, proves the outer registry state is unchanged, then drains the route to
zero.  No production behavior changes.

This is tiny because the defect and correction are confined to one test fixture
and one focused isolation test.
