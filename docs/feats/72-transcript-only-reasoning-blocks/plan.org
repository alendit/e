#+title: Transcript-Only Reasoning Blocks
#+startup: overview

* Status

Done.

* Problem

Bayesian reasoning blocks are assistant-transcript audit metadata, but current
guidance can lead an Org Canvas agent to include them in a document edit.
The runtime then persists internal =claim:= fields in a user artifact even
though the turn-finished hook only checks the final assistant message.

* Direction

The Bayesian capability owns the reserved block and the instruction that limits it to the assistant transcript.
Org Canvas clarifies that its document output excludes internal reasoning metadata without learning the fence grammar.
Resource tools remain transparent and do not rewrite agent output.

* Slices

** Slice 1: explicit model contract

- Replace "visible reply" with "final assistant transcript message."
- Forbid the block in tool arguments, capability-action arguments, files,
  canvases, temporary resources, and other artifacts.
- Clarify that Org Canvas durable output excludes internal reasoning,
  calibration, and audit metadata.

Exit condition: the combined guidance has one unambiguous destination for the
block.

** Slice 2: keep enforcement with the agent

- Do not add a Bayesian =:pre-tool-call= hook or rewrite =write= and =edit= arguments.
- Keep resource tools transparent to model output.
- Test the explicit Bayesian and Org Canvas instructions.

Exit condition: the agent receives an unambiguous contract, with no artifact-specific enforcement code.

** Slice 3: regression, cleanup, and review

- Cover the Bayesian and Org Canvas guidance.
- Remove the leaked block from feature 66 without staging its unrelated active
  edits.
- Run focused affected suites, byte compilation, and whitespace checks.
- Create =review.org= and finish the feature only with no unresolved notes.

* Compatibility

The assistant transcript format, turn-finished checker, and resource tool contracts do not change.
Existing artifacts are not scanned or rewritten.
An agent can still remove an existing leaked block with a normal edit.

* Design self-check

1. The explicit agent contract directly fixes the ambiguous instruction that caused the leak.
2. This moves toward agents keeping internal audit metadata out of user artifacts by contract.
3. The stable decision is that the block belongs in assistant output; future Org annotation support remains a separate, opt-in extension.
4. Bayesian reasoning owns its reserved metadata.  Org Canvas owns only its
   output guidance.  Resources remain policy-free.
5. The change avoids coupling Org Canvas or resource adapters to Bayesian
   syntax.
6. No new dependency on generic hooks or resource tools is added.
7. Resource side effects remain unchanged and unwrapped.
8. No new durable state is added.
9. The change adds only instruction text and has no runtime processing cost.
10. =write= and =edit= retain their existing transparent contracts.
11. Existing assistant messages and artifact reads remain compatible.
12. No legacy path is needed.
13. The agent owns expected placement mistakes; unexpected resource errors still surface normally.
14. Instruction tests prove the contract independently of the UI.
