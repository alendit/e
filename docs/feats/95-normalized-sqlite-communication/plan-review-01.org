* Review loop

** Resolved P1: task and attempt fields retained two owners

The first plan assigned timestamps, outputs, and error to both task and attempt
rows.  The corrected plan gives the task queue-lifecycle status, enqueue and
retry policy, requested harness selector, and latest-attempt reference.  The
attempt exclusively owns actual execution harness/session, timestamps,
outputs, error, and attempt history.  A bounded join reconstructs the task DTO.

** Resolved P2: attribution evidence did not discriminate current lookup

The original scenario proved only reopen.  The corrected portfolio proves the
immediate and reopened public projections, and the v7 migration fixture carries
a stale event name which must lose to the current participant row with no name
copy retained in the event.

** Resolved P3: evidence and workflow boundaries

The plan now records deterministic repository evidence, external evidence as
not applicable, and telemetry as observational.  =F95-C08= covers obsolete
schema/API/runtime compatibility paths; test disposition remains in its own
section.  Repository review/status mechanics are referenced rather than copied
into the feature contract.

** Resolved P2: unsupported participant rename

An intermediate scenario introduced a rename operation absent from the current
or planned public surface.  It was removed.  The stale-name v7 migration
partition supplies the required participant-row-precedence evidence without
expanding product behavior.

** Resolved P1: valid v7 retry/resume history was not migratable

Current v7 retry/resume destructively rewrites claimed attempt rows to
=queued=, including historical attempts later superseded by another claim.  The
final plan maps every recognized v7 attempt persisted as =queued= to
=legacy-requeued=, whether latest or historical.  Attempt creation-by-claim is
the witness.  Migration preserves available facts, invents neither settlement
time nor retry/resume cause, and rejects other non-derivable contradictions by
task and attempt key.  The scenario includes retry followed by later claim and
settlement so both history and latest reference are proved.
