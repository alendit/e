** DONE High F97-R01: Require a complete Messages start before tool admission

=e-anthropic-parse-stream= accepts =content_block_start=, =message_delta=, and
=message_stop= without =message_start=.  A batch probe containing a native
=tool_use=, block stop, =message_delta(stop_reason=tool_use)=, and
=message_stop=, but no start, returned =tool-call=, =provider-replay-item=,
and =done=.  This violates =F97-C03= and =F97-C06='s complete valid response
guard.  The Anthropic decoder must enforce start and terminal order before
releasing effects; permissive fixtures must be brought to the same contract.

** DONE High F97-R02: Emit mixed native assistant text only once

The loop appends a neutral assistant text message before ordinary tool
admission, while Anthropic's native replay substitutes the entire response,
including that text.  The reviewer captured the actual passing =F97-S4=
request: it contained a text-only assistant message and then a second
assistant array with the same text, signed thinking, the ordinary call, and
the curation call.  This violates =F97-C03= and =F97-C05='s single native
assistant envelope and changes model-visible input.  Keep durable semantic
text but remove only its proven redundant immediate wire copy.  Strengthen
the public =F97-S4= request-body assertion to detect the extra message.

** DONE High F97-R03: Advance the SSE decoder across a trailing CR

=e-anthropic--sse-decoder-feed= repeats its scan at the same position when
an HTTP chunk ends with a lone =\r=.  A bounded batch probe did not return
within three seconds.  A valid CRLF delimiter split across chunks can freeze
Emacs and prevent the idle timer from firing, violating =F97-C06=.  Retain the
partial CR for the next chunk without rescanning it; test lone-CR and
split-CRLF input at the decoder and request boundary.
