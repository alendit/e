** Closed: receipt and runtime-state lifetime

COMMIT with the same identity.  Repeated clean cycles reclaim their receipts,
and the database retains only one current-or-most-recent runtime-state row.
An unretired predecessor is replaced only after the parent-liveness proof, so
cleanup cannot discard an uncertain write owned by a recovering parent.
