* Architecture self-check

| Question | Answer |
|----------+--------|
| Useful stopping point? | Current full reference placement, exact guarded revisions and honest gating each provide a usable package boundary. |
| Final direction? | Stable reusable history with current exact Canvas observations. |
| Stable versus uncertain decisions? | Exactness and ownership are stable; byte thresholds and single-span policy are private, reversible tuning. |
| Behavior owner? | Harness owns chronology/settlement, resource owners own atomic mutations, adapters own native shape/capability, shells own editor presentation. |
| Coupling/interfaces? | Existing context, operation and resource seams carry narrow revision metadata; no separate document service. |
| Dependency direction? | Provider-neutral policy depends on core contracts; native adapters and resource implementations consume them. |
| Side effects? | Capture at contributing providers and mutation at file/buffer owners; pure patch construction has no resource effects. |
| State lifetime? | Rebuildable harness-local accepted chains, scoped by session/document/selected path/generation/layout; restart safely snapshots. |
| Performance? | Full capture and exact span construction/application are linear in operand size; byte ratios and chain limits bound retained deltas. Whole-request usage is observational. |
| Real abstractions? | Exact capture, replacement span and existing semantic/native boundaries; no speculative checkout or journal API. |
| Compatibility? | Ordinary noncanvas reads/dispatch/custom contexts preserved; incompatible material native anchors are rejected. |
| Legacy removal? | Canvas bodies leave the dynamic system prefix; no unrelated legacy migration is included. |
| Error handling? | Expected stale revisions return conflict/current revision before effects; missing sources and unexpected protocol/encoding errors surface. |
| Independent tests? | Pure policy, owner behavior, native composition, lifecycle and actual Daily graphical witnesses localize failures. |

* Limits

Section checkouts are deferred. Arbitrary shell or unrestricted Lisp mutation is outside ordinary resource revision protection. Byte defaults do not assert an optimal savings percentage. Whole-request cache counters do not isolate Canvas cost.
