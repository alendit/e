* Why the fix preserves caching

Retained facts and summaries are portable reference data, rendered at their
canonical response anchors in history. They no longer become system instructions
or move behind new history on later requests. Anthropic Messages, OpenAI
Responses (HTTP and Codex WebSocket), and Chat Completions all consume this
ordered projection. Partial compaction, detached SQLite queries, reopen/fork
and continuation identity are covered by the repository tests.

The fresh Opus run preserves the ordered native history prefix through both
keeps. Summary and erase replace or remove only their observed source while
retaining subsequent cache-read continuity. The normal-source runner records
zero capability-wrapper grants and actual native tool availability on every
request. It uses the same scenario, semantic assertions and strict classifier
as the diagnostic run.
