* Prior finding disposition

** CLOSED F88.14: one aggregate multi-tool result frame

Each live or manually resolved execution durably commits its result with a sole
=execution-settled= marker before the next tool.  Per-execution settlement opens
no observation frame.  After all calls settle, exactly one deterministic
=frame-opened= references every result once in admitted-call order and is
acknowledged before provider follow-up.

Checkpoints retain partial result prefixes, settled result identities, aggregate
frame identity, and partial aggregate-frame state.  Replay uses the same
identities, opens no frame while a call is nonterminal, and never degrades a
known durable result to ambiguity.  The public resolver shares this transaction.
Mandatory E2E and performance evidence cover the per-execution and aggregate
boundaries separately.
