* Findings

** P2 F88.A1: The proposed stateful provider simulator duplicates existing evidence

The draft requires a new stateful fake transport and computed effective-model
context.  Feature 88 already proves the provider-neutral semantics in
=e-context-lifetime-e2e-test-canvas-replacement-profiles=, including per-kind
conservatism, old-canvas disappearance, and replaceable-anchor advancement.
The existing Responses WebSocket integration already crosses the real harness
and renderer at the socket boundary.

*** Owning correction

Keep the existing generic Feature 88 effective-context test as the semantic
proof.  Minimally extend or parameterize the existing Responses WebSocket
integration for the exact built-in =codex= and =openai= profiles.  Assert the
resolved kind map, literal request shapes, =previous_response_id=, incremental
mode, and newest clean anchor.  Do not create another provider-context
simulator.

*Exact replacement direction for implementation item 3:*

#+begin_quote
In =test/e-provider-continuation-integration-test.el=, extend the existing
Responses WebSocket integration at the socket boundary to run the exact
built-in =codex= and canonical =openai= profiles without =:request-function=.
Assert the resolved five-kind map, literal first/second request shapes,
=previous_response_id=, incremental mode, and retained newest clean anchor.
Keep =e-context-lifetime-e2e-test-canvas-replacement-profiles= as the
provider-neutral effective-context and anchor-policy proof; do not add another
provider-context simulator.
#+end_quote

Remove the fake provider's computed effective-context assertion from the
package acceptance and cite the existing canvas-replacement E2E for that cell.

** P2 F88.A2: The live marker probe does not assert its no-leak precondition

The draft says the first turn is constructed so =OBSERVATION-OLD= is never
copied into durable assistant output, but does not require an assertion.  If
the first assistant response contains the old marker, that durable response is
legitimately inherited through continuation and the second answer cannot
isolate instruction replacement.

*** Owning correction

Before turn two, assert that the first assistant response and durable session
message contain no =OBSERVATION-OLD=.  Then require the second response to
report =OBSERVATION-NEW= and reject =OBSERVATION-OLD=.  A first-turn leak must
fail the conformance probe as ambiguous.
