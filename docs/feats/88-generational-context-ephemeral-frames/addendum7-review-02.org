* Findings

** TODO High P1 =F88A7.I1=: exact package retry conflicts after first append

Contract cell: =F88A7-ATOMICITY=.

Package identity hashes the session and semantic components, while duplicate
validation also compares the newly prepared parent with the historical parent
(=lisp/core/e-session.el:4221-4300=).  The first append advances the head to the
package (=lisp/core/e-session.el:4472-4478=), so an exact immediate retry has the
same ID but a different proposed parent and signals a conflict.

This breaks recovery when package append succeeds but the later audit append
fails.  Accept an exact existing package only when its type/components match
and it is on the selected path; keep rejecting off-path and conflicting
identities.  Cover immediate, descendant-head, audit-failure, reopen,
queued/controller, and sibling-conflict retries.

** TODO High P1 =F88A7.I2=: configured erase reopen gate cannot pass

Contract cells: =F88A7-PRESERVATION= and =F88A7-ADOPTION=.

The runner correctly locates the reopened event through
=:payload :receipt :tool-call-id=, then compares =:payload :receipt :receipt=
against the original receipt (=e2e/e-live-e2e-test.el:4968-5004=).  Production
has one receipt directly below payload, so a correct record yields nil on the
left.  Compare the direct receipt and add a credential-free regression for the
exact reopen predicate before running configured evidence.

** TODO Medium P2 =F88A7.I3=: obsolete APIs bypass the package authority

Contract cells: =F88A7-ATOMICITY= and compatibility/removal.

The promotion-only preparation wrapper silently discards current erasure
semantics (=lisp/core/e-context-lifetime.el:1348-1361=).  A public standalone
version-3 writer remains (=lisp/core/e-session.el:4426-4436=), and session plus
the controller writer accept a never-committed outer =context-erasure= entry
outside the package (=lisp/core/e-session.el:152-174,2385-2407,3994-4008=;
=lisp/core/e-session-writer.mjs:101-106=).

Remove the promotion-only wrapper and standalone production writer, migrating
current callers to the package.  Preserve read/replay compatibility for
committed standalone version-2/version-3 promotion records.  Remove the outer
erasure list/replay/checkpoint/writer path; keep version-1 erasure only as a
codec and nested package component.  An outer erasure must be rejected.

** TODO Medium P2 =F88A7.I5=: receipt filtering is quadratic
