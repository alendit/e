* Finding

** P3 F88.A3: Static declaration wording contradicts lookup lifetime

The addendum says profile data is already present when the backend is
constructed, which implies construction-time capture.  Current capability and
request resolution correctly re-read the normalized current profile at each
existing lookup.  Static means configuration-declared rather than runtime-
discovered; it does not mean frozen when the backend object is created.

*** Exact correction

#+begin_quote
These are static adapter/profile declarations.  Resolution reads the normalized
configured profile current at each existing profile lookup and capability
query; it never learns support by making a provider request, running a probe,
or consulting a discovery registry/cache.
#+end_quote
