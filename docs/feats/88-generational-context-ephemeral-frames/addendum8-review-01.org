* Aggregate design comparison

Accepted behavior and recovery invariants :: Multiple new frames are valid;
same-opportunity repetition is bounded; malformed semantics remain strict;
only accepted packages are durable.

Current aggregate :: A turn-wide integer in =e-loop= permits one curation-only
continuation and turns every later one into an invalid-record error, regardless
of which frame its request presented.

Smallest faithful alternative :: Use the already captured
=provider-request-lifetime-frame= as the opportunity truth, plus one turn-local
duplicate-correction budget.  Let the OpenAI decoder provide opaque normal and
corrective replay bundles; the loop selects without interpreting provider wire
shape.

Material difference :: The alternative removes the false coupling to total
turn length, introduces no durable identity set or cross-owner transaction, and
keeps provider syntax in the adapter.  It is both smaller and more faithful
than expanding the old turn-wide counter.

Decision :: Use the frame-scoped alternative.  Replace the regression that
expects =e-context-lifetime-invalid-record=; retain and strengthen ordinary
acknowledgement, strictness, replay, and atomicity tests.

* Architecture and performance review

The plan preserves dependency direction.  Stable core frame semantics do not
depend on OpenAI, Board, or presentation.  The loop owns sequential protocol
state because it already captures the request frame and starts immediate
continuations.  The adapter supplies opaque wire bundles instead of exporting
provider item structure into core.  Session receives only accepted semantic
packages.  The duplicate terminal-notice correction stays at the independent
Board/chat presentation boundary.

The relevant physical owners remain cohesive after Feature 91.  No new module
or abstraction is justified: each change is small and belongs to an existing
owner with the same reason to change.  The normal path adds constant predicates;
the exceptional path adds at most one request and one turn-local scalar.  There
is no scan, polling loop, persistent recovery state, or unbounded identity set.
