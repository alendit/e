* Confirmed findings

** P2 F004 — Present malformed board state falls through to legacy mirrors

Classification: incomplete prior closure of F002.

Proof:

=e-session--index-entry-session= reconstructs board state with a truthy =or=:

#+begin_src emacs-lisp
(or (copy-tree (plist-get entry :board-state))
    (when (and (plist-get entry :board-id)
               (plist-get entry :principal))
      ...))
#+end_src

This collapses a missing =:board-state= key and a present nil or empty invalid
value into the same legacy case.

=e-chat-service--root-session-p= then selects nested and flat fields
independently:

#+begin_src emacs-lisp
(board-id (or (plist-get state :board-id)
              (plist-get session :board-id)))
(principal (or (plist-get state :principal)
               (plist-get session :principal)))
#+end_src

Consequently, a catalog entry carrying a partial nested owner plus a flat
principal is advertised as a root.  A scalar =:board-state= reaches =plist-get=
and raises =wrong-type-argument=, allowing one malformed entry to abort catalog
traversal.

The independent reproducer returned exactly:

#+begin_example
(t (:error wrong-type-argument))
#+end_example

This contradicts the investigation claim that explicit malformed or partial
persisted state remains non-root.

Owner and principled correction:

=e-session= owns the durable association schema and must preserve the
distinction between an absent legacy representation and a present invalid
representation at index and journal ingress.  A present association must be
normalized or rejected as one bounded whole: string board id, string principal,
and absent or valid scalar role.  Flat board-id/principal mirrors may reconstruct
state only when the nested representation key is genuinely absent.

=e-chat-service= should consume one normalized association rather than combining
nested and flat fields independently.  Explicit invalid state must not fall into
legacy inference.  Do not catch errors in pickers, treat every malformed value
as legacy, or add another shell-side filter.

Required regressions:

- missing nested state plus canonical flat legacy fields remains readable;
- present nil or empty nested state plus flat fields is not promoted;
- present partial nested state cannot borrow fields from flat mirrors;
- scalar or list-invalid nested state does not abort the root catalog;
- valid explicit owner/participant and canonical legacy cases remain unchanged;
- malformed cases pass through an actual index-store/catalog boundary, not only
  the private predicate.

* Progress and fixed-point assessment

The remediation closes the visible Daily duplication, Canvas bypass, and
supported cross-store same-id case at their owning boundaries.  It also improves
public and restart evidence.

Fixed point is not reached because explicit malformed representation is not kept
distinct from absent legacy representation.  F004 leaves duplicated nested/flat
semantic authority and can advertise an invalid root or abort the whole catalog.

After remediation and an exact-revision gate, a fresh independent Tick is
required.

* Architecture self-check

1. The package is better than its baseline: normal and cross-store private
   participants are hidden across all known selectors.
2. It moves toward explicit durable association ownership with one chat-service
   navigation policy.
3. Owner/participant role is stable.  Legacy absence is real compatibility;
   invalid presence is currently conflated with it.
4. =e-session= owns durable association representation; chat service owns role
   establishment and root semantics; presentation consumes the service.
5. Presentation coupling is reduced.  F004 identifies remaining coupling
   between two physical projections of one semantic state.
6. Shell dependency direction is correct.  The defect is inside the stable
   persistence-to-service boundary.
7. Association writes stay in chat service/session persistence; catalogs remain
   side-effect free.
8. The role has session/board-association lifetime and is written once by normal
   constructors.  Durability is justified by cross-store ambiguity.
9. Normal filtering remains linear with constant bounded work.
10. Explicit roles are real and substitutable; malformed representations violate
    the normalized contract.
11. Canonical role-absent data requires compatibility.  Flat fallback should
    apply only when nested state is absent.
12. Remove per-field fallback mixing present nested state with flat mirrors.
13. Invalid role writes fail before mutation; malformed replay/index state can
    still be promoted or abort listing.
14. Main owner/public routes are covered, but malformed evidence needs actual
    index-boundary absent/present partitions.
