* Report

The user reported that search/resource tool calls fail in chat with:

#+begin_example
Wrong type argument: char-or-string-p, (:type tool_call :id "..." :name "glob" :arguments (:uri "session:///" :limit 20))

structured transcript content as stable text instead of passing raw plists to
