#+title: Daily Fanout Times Out the Runtime Store
#+startup: overview

* Report

After restarting Emacs and starting the Grimoire Daily update, the input
surface reported:

#+begin_example
Runtime store worker is unavailable: "Store is unavailable; close, reopen, and reload canonical state"
#+end_example

The Daily controller had started its GitHub worker and was admitting its GUS
worker.  The runtime store then became permanently unavailable for the Emacs
process, so an otherwise idle chat could no longer persist a new turn.

* Expected behavior

Concurrent Daily child admission must remain bounded without killing the
shared runtime-store worker.  If a worker request does fail, the first causal
error and operation must remain visible instead of being replaced by the
generic subsequent-use error.
