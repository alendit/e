#+title: Active OpenAI HTTP Stream Times Out After 180 Seconds
#+startup: overview

* Report

The user reported that a Grimoire implementation turn repeatedly displayed
=Thought failed after 2min 59sec= and restarted its thinking indicator.  The
visible transcript accumulated several identical failed attempts without
finishing the requested work.

An initial fix changed the OpenAI HTTP timeout from an absolute deadline to an
idle deadline.  After restarting Emacs, the user reproduced the same failure on
a short =continue= prompt.  The resumed daily session still sent its retained
Grimoire history: 145 input messages in a 972,399-byte serialized request, with
high reasoning effort.  The recurrence showed that the first fix and its live
test had not covered the reported request shape.

Expected behavior: the default OpenAI HTTP path must permit a gateway to buffer
a healthy long-reasoning response.  An explicit provider timeout may enforce an
idle interval when the selected provider guarantees observable progress, but
the runtime must not assume that guarantee by default.
