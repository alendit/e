* Report

After the 2026-08-03 Grimoire daily run completed, asynchronous session
persistence remained unsettled with 24 queued writes.
The last error was a JSON encoding failure for an
=e-board-runtime-endpoint-token= value.

The affected records were user messages and =turn-steered= activity events from
three child sessions on the daily board.
The writer kept retrying the same locally unencodable records.

The failure recurred in session =20260803T164156-136fc3d8a0af= after the
persistence preflight fix was loaded but the endpoint-token removal in the
harness was not.  In that mixed-version runtime, the deterministic JSON error
failed the turn visibly but did not enter the persistence outbox or start a
retry loop.
