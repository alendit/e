same-root cutover, and sibling backup preservation.  Default composition owns
runtime-root selection and lazy =:chat-default= construction.  The session
facade owns detached catalog stubs and first-access transcript restoration.

* Source finding and correction

The first focused run failed the zero-read assertion with all 64 session IDs.
=e-runtime-migration--import-sessions= had committed canonical record batches
and =e-runtime-migration--import-session-checkpoints= had installed translated
checkpoints, but migration closed the runtime without publishing a catalog.
The next ordinary open therefore entered
=e-session--reconcile-journal-roots= and read one page per session.

The correction keeps policy in the session owner:

- =e-session-rebuild-catalog= enumerates durable session IDs, restores one
  session through the checkpoint-aware replay path, falls back to full replay
  only for that one checkpoint-less session, derives its detached index entry,
  and immediately unloads it before continuing;
- =e-session-storage-publish-catalog-projection= is a narrow catalog-only
  storage port.  It neither writes nor marks checkpoints clean;
- offline migration calls that owner operation after record and checkpoint
  import and before unrelated owner imports and final verification.

Copying the legacy =index.json= directly was rejected: it is a rebuildable
input-quality witness and can be stale.  Calling =e-session-load= followed by
=e-session-refresh-index= was also rejected because it would materialize every
session concurrently and rewrite translated checkpoints.

* P2 realization and assertions

=E2E-C02= uses the same 64-session copied-source cutover fixture, then creates
one new chat session through =e-chat-service-create-session= in the migrated
default composition.  This is intentional: P1 owns exact restoration of a
retired plain session journal, while P2 owns a Board-associated chat created by
the current service after cutover.

For both stateless and anchored profiles, the test:

- resolves the registered =:chat-default= factory with the migrated SQLite
  session store;
- submits =Hi= through durable Board routing and the attached turn port;
- injects only the Responses HTTP transport, whose first SSE response contains
  one valid =context-curate= call and no assistant output;
- requires exactly one immediate follow-up.  Stateless input contains the
  matching call before its acknowledgement; anchored input contains exactly
  the matching acknowledgement and names the retained response ID;
- observes one durable curation record, no tool-call/tool-result message, no
  tool continuity classification, and no =tool-started=/=tool-finished=
  activity;
- observes the final assistant answer in both the session transcript and Board
  output;
- closes the default runtime, clears process-local Board/chat state, recreates
  =:chat-default= on the same SQLite root, and verifies the curation and answer;
- sends =Later= and proves the new request input contains neither the old
  curation call nor its acknowledgement identity, while its assistant answer
  persists normally.

The injected transport is the only fake owner boundary.  Migration, default
composition, session storage, Board/chat delivery, harness loop, curation
preflight/commit, and OpenAI request construction are production code.  Before
=d3df89b0= the first response would terminate at
=e-loop-empty-output (curation :missing-ack-target)=.  The cold-reopen/later
request assertions additionally cover the request-local lifetime corrected by
=d8861d5f= without duplicating its focused provenance matrix.

=d8861d5f6828f882b963379f829c7119dfa1f81c=.  It found no actionable P0--P3

The full 2,704-test preservation run was not repeated after the final
blocking-inventory expectation changed.  The directly affected selector
passed independently.  The other observed full-run failures reproduced as
existing timing, local-socket, Emacs 31, or Org-fold environment cases.  The
64-session fixture is a structural lazy-loading gate, not an operator-scale
performance benchmark; the existing copied-store measurements remain the
scale evidence.
