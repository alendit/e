#+date: 2026-09-24

* Report

After the canonical JSON UTF-8 repair, reopening the 2026-09-23 Grimoire
Daily showed a partial result from Board =brd_3057f14764b66960208a89866978b5ad=.
The operator then asked how to trigger a fresh run.

The documented =grimoire-daily-update= and =grimoire-daily-tick= entry points
did not provide a reliable fresh same-day run.  They found the prior terminal
run by Daily date and path and reopened its coordinator instead of allocating
a new run identity and worker set.

Expected behavior:

- an unfinished, admitted, running, or conflicting run is recovered without
  duplicate work;
- after the coordinator reaches any non-conflicting durable terminal outcome
  (=done=, =failed=, or =cancelled=), the next update creates one fresh run;
- a failed or cancelled old run remains durable historical attention and is not
  relabeled successful; and
- =E_BOARD=, earlier manifests, attempts, and Board history remain intact.
