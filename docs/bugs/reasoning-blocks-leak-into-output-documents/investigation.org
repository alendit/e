#+startup: overview

* Runtime evidence

The user's screenshot shows the reserved block at lines 23-28 of
=docs/feats/66-work-bus-interaction-model/plan.org= while the Org Canvas chat is
the active writing surface.

The persisted session
=20260730T114623-5dda3541b757= contains the write that introduced the first
version of this block.  The model called the =edit= resource tool with the
reasoning fence embedded in an edit's =newText=.  The block later remained in
commit =826e79e8=.

The later session =20260731T130839-bd8284d66d4c= read the already polluted
document.  Its user prompt explicitly requested a separate replacement at
=tmp://merged-plan.org= with all reasoning blocks removed.

The screenshot and persisted tool call provide live and durable reproduction
evidence without requiring a full Emacs reload.

* Code findings

1. =e-bayesian-reasoning-instructions= says to emit the block in the "visible
   reply" but does not say that this means the final assistant transcript
   message only.
2. Org Canvas guidance says the document is the primary output target and that
   durable results belong there.  In combination, the model can reasonably
   treat the document edit as the visible reply.
3. The Bayesian capability registers the block as hidden assistant output, but
   has no artifact-write boundary.  =write.content= and =edit.edits[].newText=
   reach resources unchanged.
4. The turn-finished checker reads only assistant message content.  A block
   placed only in a tool argument cannot help the audit and only pollutes the
   artifact.

* Direction

Make the transcript-only rule explicit in both Bayesian and Org Canvas
guidance.  Add a Bayesian pre-tool hook that removes reserved reasoning fences
from =write= content and =edit= replacement text before resource mutation.
Keep =edit.oldText= unchanged so an agent can remove a block that already
exists.  Do not add Bayesian knowledge to Org Canvas write code or generic
resource adapters.

Implementation is tracked by
=docs/feats/72-transcript-only-reasoning-blocks/plan.org=.
