#+title: Subagent await rejects handles as unknown board work

* Report

A parent session spawned six direct subagents and then called the model-facing =await= tool with their =subagent:<id>= references.
The call failed immediately with =e board error: "Unknown board work"= for a subagent work id.
A retry on the still-running subset failed the same way.
The children continued running until the parent cancelled four of them and completed their tasks inline.

* User-visible impact

- Fan-out succeeds, but fan-in fails.
- The parent cannot use the prescribed event-driven await path.
- A parent may mistake active children for stalled work and cancel them prematurely.
- Slow child-owned tools can also fail when the child tries to await detached =work:bash/...= handles.
